SafeBite Travel UI/UX Design · PWA
Allergy-aware travel food assistant

A calm, trustworthy PWA that helps allergic travelers understand local food and ask the right questions.

This is a visual design system + screen showcase built from PRD v0.2 and the Phase 0/1 spec. The product's promise is risk reduction, not risk elimination — so the UI never claims a dish is risk-free. Every recommendation shows source, confidence, reason, action and last checked.

Design system

Foundations shared across every screen. Colour never carries meaning alone — each status pairs an icon + label.
