SafeBite Travel Design system v2
Allergy-aware travel food assistant

From mock to a production-grade, accessible mobile design system.

Rebuilt from verified research (WCAG 2.2 contrast-checked, Lucide icon system, color-blind-safe status ladder). The product promise stays honest — risk reduction, not risk elimination — so no screen ever claims a dish is risk-free. Every recommendation shows source, confidence, reason, action and last checked.

Non-alarmist & transparent WCAG 2.2 AA/AAA EN / VI bilingual Offline-first PWA

Foundations

Tokens verified by the design research: 4-level surface ladder, ocean-blue brand ramp, one warm appetite accent (fill only), elevation & radius scales, 8pt spacing, modular type. Colour never carries meaning alone.

Mobile design principles → how SafeBite applies them

The full principle set you specified, each with a concrete rule (numbers) and where it lives in the UI. Sourced from Apple HIG · Material 3 · NN/g · WCAG 2.2, verified in the research pass.

PrincipleConcrete ruleIn SafeBite
Thumb ZonePrimary action in bottom third; 16px side margins; above safe-area.Every screen's single CTA is bottom-anchored full-width; back/close in top corners.
Touch Target≥48×48px (Apple 44pt / Material 48dp); glyph 20–24px, hit area padded.Buttons, nav items, chips, icon buttons all ≥48px.
Haptic FeedbackSecond signal only; escalates with the status ladder; success on save; never on scroll.Dish result reveal, save-phrase toast (annotated — real haptics in the RN/PWA build).
GesturalEvery gesture has a visible button twin; never hide critical actions behind gesture only.“Why this rating” is a tappable row, not a hidden swipe.
Visual HierarchyOne primary action; verdict is the largest element; source demoted to body-s/muted.Dish result: big status chip + one-line reason first.
Negative Space≥24px above CTA; ≤8px within a group; ≥24px between groups; ~40–55% breathing room.Result/restaurant cards; onboarding.
Typographic Scaling16px base, ~1.2 minor third; never <14px for actionable text; 12px = legal/timestamps.Status label = title; timestamp = caption.
Contrast RatioText ≥4.5:1; icons/borders/focus ≥3:1. All 30 status values verified.Status tokens + build-time gate + visible 2px focus ring.
Grid8pt grid + 4px half-step; single column capped at 480px; 16px gutters.Whole showcase; scales to tablet/desktop unchanged.
Progressive DisclosureVerdict + one line first; breakdown/source behind “Why this rating” (300ms).Dish detail; filters sheet with defaults pre-applied.
3-Click RuleCore jobs ≤2 taps from any top-level screen; never bury a risk result.Scan→result = 2 taps; find suitable restaurant = 2 taps.
Bottom Navigation3–5 items; icon 24px + always-visible label; active = tinted pill; ≥48px; 56px + safe-area.Home · Dishes · Card · Profile (Nearby in Phase 2).
BreadcrumbsNo horizontal breadcrumbs on mobile; 48px back affordance + context title.Every non-root screen top bar (“‹ Mì Quảng gà”).
Onboarding Flow≤3 screens to value; honest promise; only allergen step required; locale-default language.Landing → Allergens → Severity → Safety.
GestaltGroup by spacing; all 5 status pills identical shape so only icon+color+label vary.Status ladder everywhere it appears.
Cognitive LoadRecognition over recall; plain one-line copy; defer detail.Saved allergens shown as persistent chips on scan/filter.
Hick's LawOne primary action; nav ≤5; filter chips ≤6 then “More”; allergen quick-picks ≤8 then search.Filters sheet; allergen picker with search.
Fitts's LawPrimary CTA biggest + closest (full-width bottom); destructive smaller + far (top corner).Scan FAB 28px; full-width result CTA.
Mental ModelsReuse conventions: risk ladder = traffic/severity; list = map-app cards; phrasebook = chat card.“Ask First” speech-bubble reinforces “talk to staff”.
Skeleton ScreensShape-match; shimmer 1200–1500ms; 200ms delay; >10s/fail → error+Retry; reduced-motion → static.Dish-guide load specimen.
Empty States48–64px monoline glyph + one line + one primary action; never blank/alarmist.“No dishes match those filters” → Clear filters.
Error StatesWhat + why (plain) + recovery; offline non-blocking with cache; field errors inline icon+text.Scan failure → Retake photo; offline banner.
Success StatesBottom toast above nav; checkmark + short text; auto-dismiss 4s; persist if it has Undo.“Chef card saved · Undo”.
Micro-interactionsTap 100ms; transitions 200ms; sheet enter 300ms decel / exit 250ms accel; reduced-motion → ≤100ms opacity.Button press scale, toast slide, nav pill.
Platform Specificityviewport-fit=cover + env() insets; iOS vs Android install tips; 16px inputs (no iOS zoom).Install card; inputs; safe-area padding.
Responsive / AdaptiveSingle column; center + cap 480px on large; gutters bump ≥414px; nav hides on deep flows.All screens; showcase reflows.
Dark ModeElevation = lighter surface + hairline top; canvas #0a0f1a not pure black; toggle overrides system.Full dark token set; theme toggle.
Accessibility (a11y)WCAG 2.2: 4.5:1, 3:1 non-text, colour never sole signal, ≥24px targets, focus ring, aria on icons.Status = icon+label+color; aria-labels on icon buttons.
Input MaskingFormat-as-you-type but store raw; never block paste; show format as helper; inputmode; ≥16px.Phone field on chef card.
Autofill / AutocompleteCorrect tokens (name/email/tel); type/inputmode/enterkeyhint; never autocomplete=off on personal fields.Chef contact form.
Inline ValidationKeystroke = help; blur = correctness (only if edited); after error → re-validate on fix.Email field error clears on correction.
Smart DefaultsLanguage = locale; saved allergens pre-selected; missing data → Unknown/Ask First, never Suitable.Scan, filters, onboarding, language toggle.

States & motion spec

Timing, easing, elevation and the reduced-motion contract — the rhythm every animation shares.

Durations

200mscontrol transitions
300mssheet / dialog enter
250msexit (faster than enter)

Easing

Standardcubic-bezier(.2,0,0,1)
Emphasized decelerate — entrancescubic-bezier(.05,.7,.1,1)

Reduced motion

Toggle “Reduce motion” in the top bar. Under it, shimmer/slide/scale collapse to ≤100ms opacity fades and the marbles above stop.
